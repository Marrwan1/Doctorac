# Doctorac



###### Doctorac is a Healthcare Management System built with Flutter and Dart.

###### 

## Requirements

###### Flutter SDK

###### Git

###### Visual Studio Code or Android Studio

###### Getting Started



Clone the repository:

**git clone https://github.com/Marrwan1/Doctorac.git**

**cd Doctorac**



**Install dependencies:**

**flutter pub get**



**Run the application in Chrome:**

**flutter run -d chrome**



**Check your environment:**

**flutter doctor**



**Project Structure**

**assets/: Images, icons, fonts, and other application assets.**

**lib/core/: App-wide utilities and configuration.**

**lib/shared/: Reusable widgets and shared code.**

**lib/features/: Feature-specific application code.**

**test/: Automated tests.**

**pubspec.yaml: Dependencies and asset configuration.**





**Team Workflow**

**Each developer should create a separate branch for their feature.**



**git switch main**

**git pull origin main**

**git switch -c feature/feature-name**



**Before opening a Pull Request, run:**



**flutter analyze**

**flutter test**





**Commit and push your changes:**

**git add .**

**git commit -m "feat: describe your change"**

**git push -u origin feature/feature-name**





**Then open a Pull Request on GitHub for review before merging into main.**
